Log loss on settled matches recorded by the watch (live.db), model against the Kalshi market mid. Difference = model − market: negative means the model priced the winner better. Pre-match uses the last priced poll before the match went live; in play averages every live poll per match, so each match counts once. ± is one standard error across matches.

Running chart: the difference over all settled matches so far, in settlement order, with a ±2 SE band. A model lead that holds keeps the line below zero as the band narrows.

Feed lag: correlation of the model's move (driven only by the score feed) with the market's move k polls later. A peak at k < 0 means the market moved before the feed showed the point. Same numbers as scripts/watch.py scorecard.
